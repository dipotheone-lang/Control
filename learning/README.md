# learning/

Learning engine records — charter §14.5: `proposals/` (every adaptation,
with trigger, evidence, expected effect, direction) · `applied/` (Tier A
applications with rollback records) · `rolled-back/` (learning failures,
raised in the weekly report) · `baselines/` (statistical baselines from
Stage F onward).

Tightening applies autonomously (Tier A, ADAPTIVE mode only); loosening
always requires CEO approval. See `config/learning-policy.yaml`.
